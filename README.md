# email-validator
📧 Email Validator Web App

📝 Overview

The Email Validator is a simple web application that allows users to verify the validity of an email address using JavaScript. The application checks the email format using regular expressions and provides instant feedback.

✨ Features

✅ Validate email addresses in real-time.
❌ Display error messages for invalid email formats.
🎨 Simple and user-friendly UI.
⚡ Lightweight and fast performance.

<br>
🛠 Technologies Used

🏗️ HTML: Structure the web page.
🎨 CSS: Style the user interface.
⚙️ JavaScript: Handle validation logic.

Clone the repository:
git clone git clone https://github.com/ensanya/email-validator.git

Navigate to the project folder:
cd email-validator

Open index.html in a web browser.


🚀 Usage

Enter an email address into the input field.

The app will validate the input in real-time.

✅ If the email is valid, a success message will appear.

❌ If the email is invalid, an error message will be displayed.
